# Baseball Intelligence

> 目前狀態：專案初始化（僅有骨架與文件，尚未實作任何功能）

## 專案要解決的問題

球隊每天都會累積大量比賽數據，但「數據」本身不等於「可以用的資訊」。
本專案的核心目標是：

**從數據中找到球隊值得注意的資訊。**

也就是把原始比賽紀錄，轉換成分析人員看得懂、且有數據佐證的 insight。

## 目標使用者

球隊的數據分析人員。

- 案例球隊：富邦悍將
- 資料範圍：CPBL

## MVP 的三個主要方向

MVP 想回答的三個問題：

1. **球隊目前近況** — 最近的表現走勢是什麼樣子
2. **特別需要注意的球員** — 誰的狀態出現值得關注的變化
3. **下一場對手** — 對手有哪些需要事先掌握的特徵

每一個 insight 最終都應該同時提供：

1. 數據佐證
2. 與下一場比賽的關聯
3. 決策支援的方向

## 目前尚未具備的能力

為避免誤解，明確列出**目前還沒有**的東西：

- 沒有 CPBL 資料抓取功能，也沒有任何 API client
- 沒有資料庫
- 沒有 Web API、前端或 dashboard
- 沒有 LLM 相關功能
- 沒有任何分析程式碼
- `data/` 目錄目前是空的，專案不會產生假資料來假裝功能已完成

專案仍在探索資料來源階段，資料粒度與可取得的欄位都還沒有確定。
